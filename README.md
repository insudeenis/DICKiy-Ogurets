# Stats Analyzer

Приложение для анализа статистических данных с графическим интерфейсом.

## Участники команды

| Участник | Аккаунт | Вариант | Ветка |
|----------|---------|---------|-------|
| Александр | rultted | Вариант 3 — Погода | Sasha`s-Branch |
| Ирина | isendensus | Вариант 9 — Цены на квартиры | Ira`s-Branch|
| Никита | ReldonNTs | Вариант 16 — Плохие дороги | Nikita`s-Branch |

## Модули

### Вариант 3 — Анализ погоды
- Загрузка данных о температуре из JSON файла
- Таблица с данными за месяц (мин температура синим, макс красным)
- Графики максимальной, минимальной и средней температуры
- Статистика перепадов температуры
- Прогнозирование методом скользящей средней на N дней

### Вариант 9 — Анализ цен на квартиры
- Загрузка данных о ценах из csv файла
- Таблица с ценами по месяцам
- Графики изменения цен
- Статистика максимальных и минимальных значений
- Прогнозирование изменения цен методом скользящей средней на N дней

### Вариант 16 — Анализ доли плохих дорог
- Загрузка данных о плохоих дорогах из csv файла
- Таблица с долями плохоих дорог
- Графики изменения сосотяния дорог
- Прогнозирование изменения цен методом скользящей средней на N дней

## Технологии

- **Python 3.14**
- **PyQt6** — графический интерфейс
- **Matplotlib** — графики
- **Pandas** — обработка данных

## Структура веток

- `main` — финальная версия релиза
- `Sashas-Branch` — модуль погоды (rultted)
- `Iras-Branch` - модуль цен на квартиры (isendensus)
- `Nikitas-Branch` — модуль дорог (ReldonNTs)
